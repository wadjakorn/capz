## Landed

- **WYSIWYG capture — capz can capture its own editor** (2026-10-16) — captures now take the screen exactly as the user sees it. The editor is hidden only when the capture starts from the editor's own toolbar ("capture what's behind me"). Hotkey, command ring and tray capture leave it in place, so a visible editor (pinned on top or not) lands in the shot and a buried one stays buried. On macOS this needed non-activating `NSPanel` capture windows (`tauri-nspanel` 2.1.1, `src-tauri/src/panel.rs`): the overlays, the click ring (v1) and the scroll HUD take keys without activating capz, which used to pull the editor in front of the app being captured. The hold ring (v2) stays a plain window and never takes key (CP-0038). Window mode lists the editor whenever it is visible. On macOS hit-testing is now front-to-back over normal-layer windows only, so other apps' floating overlays no longer swallow hovers and small windows behind the editor no longer win. On Windows xcap can't see our own windows, so the entry is built from the editor's DWM frame bounds and captured as a monitor crop (`services/self_window.rs`). Instant full-screen waits one frame so a closing ring or tray menu is gone. **Behaviour change:** pressing a capture hotkey while working in the editor now includes the editor.

- **History preview overlay** (landed 2026-10-05) — selecting a History item shows it large over the canvas (`src/components/editor/HistoryPreview.tsx`); deselecting, Esc, ✕ or clicking the dim closes it, and switching sidebar tab hides it without dropping the selection. The bar repeats the item's sidebar actions (Reveal / Copy / Trash, now one shared `useHistoryActions` hook) plus **Add to current workspace** (same path as dropping a row; double-click the picture does the same). Smoothness: the in-memory 128px thumb paints blurred on the click frame, then a canvas-sized JPEG from the new `read_image_preview` command (raw bytes via `ipc::Response`, not base64) is decoded off-screen and faded in; a 6-entry LRU of blob URLs (`src/lib/historyPreview.ts`) plus a 120 ms hover prefetch make most clicks hit cache. Only opacity/transform animate; no backdrop blur. Verified: unit tests, `tsc`, `pnpm build` + `cargo clippy -D warnings` on the Mac; interactive Mac check pending.
