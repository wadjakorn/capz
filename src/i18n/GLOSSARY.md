# Thai UI glossary

The UI ships in Thai (default for new installs) and English. Use this table so
one concept always gets one Thai word. Add to it when you introduce a new term.

## Voice

- Short, plain, polite-neutral. No ค่ะ/ครับ/นะ, no exclamation marks.
- Buttons are verbs: บันทึก, คัดลอก, ยกเลิก — not "กดเพื่อบันทึก".
- Keep it as short as the English where the space is tight (toolbar, tabs,
  ring wedges). Prefer a common loanword over a long native phrase when Thai
  users already say it that way (เลเยอร์, สติกเกอร์, ไฟล์).
- No space before/after Thai text inside a sentence except between clauses,
  as normal Thai typography. Put a space between Thai and Latin words/numbers:
  "ขนาด 64 px", "เปิด capz".
- Trailing ellipsis (…) stays where the English has it (opens a dialog / in
  progress). Thai sentences drop the English trailing full stop.
- One Thai form serves both plural keys ("{n} ไฟล์"); English keeps
  separate One/Many keys.

## Never translate

capz, macOS, Windows, PNG, JPEG, OCR, GitHub, Homebrew, keyboard key names
(⌘ Ctrl Shift Alt Esc Enter Space), accelerators ("CmdOrCtrl+Shift+4"), file
paths, backdrop preset names (Slate, Gingham, Bauhaus…), px / % units.
