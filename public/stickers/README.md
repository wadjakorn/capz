# Built-in sticker art

- **Source:** generated for capz with OpenAI image generation (gpt-image, via Codex) in October 2026 (CP-0048). Under OpenAI's terms the output belongs to the requester; no third-party attribution is required.
- **Style:** flat vector, white die-cut outline, palette coral `#FF5A5F` / amber `#FFB020` / mint `#22C55E` / sky `#3B82F6` / violet `#8B5CF6` / ink `#1F2937`. No letters on any sticker (the UI is Thai by default).
- **Format:** 256×256 lossy WebP (quality 90), transparent.
- **Ids are persisted** (annotation `src`, `lastUsed.stickerItem`): never rename or reorder files. Add new stickers as new files and append them in `src/lib/stickers/builtin.ts`.
