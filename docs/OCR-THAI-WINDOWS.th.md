# การอ่านตัวอักษรภาษาไทย (OCR) บน Windows

> เอกสารนี้เขียนเป็นภาษาไทยแบบเข้าใจง่าย สำหรับผู้ใช้ทั่วไป (ไม่ใช่สายเทคนิค)

## สรุปสั้น ๆ

**บน Windows capz ยังอ่านภาษาไทยไม่ได้ และตอนนี้ยังไม่มีวิธีทำให้อ่านได้**
ไม่ต้องเสียเวลาไปหาติดตั้งอะไรเพิ่ม — **ไม่มีของให้ติดตั้ง**

ภาษาอังกฤษ (และอีกหลายภาษา) ยังอ่านได้ตามปกติ

> ℹ️ เอกสารฉบับก่อนหน้านี้เคยแนะนำให้ไปติ๊ก “Optical character recognition”
> ตอนเพิ่มภาษาไทยใน Windows Settings — **คำแนะนำนั้นผิด** ทำตามแล้วก็จะไม่เจอ
> ตัวเลือกนั้น เพราะมันไม่มีอยู่จริงสำหรับภาษาไทย ขออภัยที่ทำให้เสียเวลาครับ

---

## ทำไมถึงเป็นแบบนี้?

capz บน Windows ใช้ระบบอ่านตัวอักษรที่ติดมากับ Windows เอง (`Windows.Media.Ocr`)
ซึ่งอ่านได้เฉพาะภาษาที่ Microsoft ทำ “ชุด OCR” ไว้ให้เท่านั้น

จากตารางรายการชุดภาษาของ Microsoft เอง มีชุด OCR ทั้งหมด **35 ภาษา**
เช่น อังกฤษ ญี่ปุ่น จีน เกาหลี เยอรมัน ฝรั่งเศส รัสเซีย ฯลฯ — **แต่ไม่มีภาษาไทย**

สิ่งที่ทำให้สับสนคือ Windows **มี** ชุดที่ชื่อ `Language.Fonts.Thai` อยู่จริง
แต่นั่นคือ **ชุดฟอนต์** (ไว้แสดงผลตัวอักษรไทยให้สวย) ไม่เกี่ยวกับการอ่านตัวอักษร

พูดง่าย ๆ: Windows แสดงภาษาไทยได้ แต่ *อ่าน* ภาษาไทยจากรูปภาพไม่ได้

---

## แล้วมีทางไหนบ้าง?

| ทางเลือก | ใช้ได้ตอนนี้ไหม |
|---|---|
| ใช้ capz บน **macOS** | ✅ ได้ — ระบบ OCR ของ macOS รองรับภาษาไทย |
| ใช้ capz บน **Windows** | ❌ ยังไม่ได้ |
| ติดตั้งชุดภาษาไทยเพิ่มใน Windows | ❌ ไม่มีชุด OCR ไทยให้ติดตั้ง |

ทีมงานกำลังหาทางเลือกอื่นสำหรับ Windows อยู่ (ใช้ระบบ OCR ตัวอื่นที่รองรับไทย)
ถ้าคืบหน้าจะแจ้งผ่านหน้า Releases

---

## อยากตรวจสอบเองว่าจริงไหม?

ถ้าคุณใช้ Windows อยู่ เปิด **PowerShell** แล้วพิมพ์คำสั่งนี้ดูได้:

```powershell
Get-WindowsCapability -Online -Name "Language.OCR*" | Select-Object Name, State
```

จะเห็นรายการชุด OCR ทั้งหมดที่ Windows มี — จะไม่มีบรรทัดไหนที่เป็น `th-TH`
