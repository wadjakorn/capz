# การอ่านตัวอักษรภาษาไทย (OCR) ใน capz

> เอกสารนี้เขียนเป็นภาษาไทยแบบเข้าใจง่าย สำหรับผู้ใช้ทั่วไป (ไม่ใช่สายเทคนิค)

## สรุปสั้น ๆ

ตั้งแต่ capz รุ่น 0.21 ปุ่ม **ตรวจหาข้อความ** อ่านภาษาไทยได้แล้วบน Windows
และอ่านไทยกับอังกฤษที่อยู่ในบรรทัดเดียวกันได้ด้วย **ไม่ต้องติดตั้งอะไรเพิ่ม**

| เครื่อง | ตัวอ่านข้อความที่ใช้ | อ่านไทยได้ไหม |
|---|---|---|
| Windows | OpenThai (มากับ capz) | ✅ ได้ |
| macOS | Apple Vision (ค่าเริ่มต้น) | ✅ ได้ บน macOS 13 ขึ้นไป |
| macOS | OpenThai (เลือกเองได้) | ✅ ได้ |

> ℹ️ capz รุ่นก่อน 0.21 บน Windows อ่านภาษาไทยไม่ได้ เพราะใช้ระบบ OCR ของ
> Windows เอง (`Windows.Media.Ocr`) ซึ่ง Microsoft ไม่ได้ทำชุดภาษาไทยไว้
> ถ้าเคยเห็นคำแนะนำให้ไปติดตั้งชุด OCR ภาษาไทยใน Windows Settings ไม่ต้องทำตาม
> เพราะชุดนั้นไม่มีอยู่จริง

---

## OpenThai คืออะไร?

OpenThai2.0-OCR-Text เป็นโมเดลอ่านตัวอักษรของบริษัท iApp Technology
ทำมาสำหรับภาษาไทยโดยเฉพาะ และอ่านภาษาอังกฤษได้ด้วย
capz ใส่โมเดลนี้มาในตัวโปรแกรมเลย (ขนาดราว 4 MB)

- **ทำงานบนเครื่องของคุณทั้งหมด** ไม่มีการส่งภาพขึ้นอินเทอร์เน็ต
- ใช้หน่วยความจำมากกว่าระบบ OCR ของ macOS และอาจช้ากว่าเล็กน้อย
  บนภาพหน้าจอใหญ่ ๆ อาจใช้เวลาราว 1 วินาที

---

## บน Mac จะเปลี่ยนไปใช้ OpenThai ได้อย่างไร?

1. เปิด **ตั้งค่า → ตัวแก้ไข**
2. กด **ขั้นสูง** ด้านล่างของหน้า
3. ที่ **ตัวตรวจหาข้อความ** เลือก **OpenThai**

ถ้าอยากกลับไปใช้แบบเดิม ให้เลือก **Apple Vision (ค่าเริ่มต้น)**
